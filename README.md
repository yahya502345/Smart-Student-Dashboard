## About

I built this while learning React — a simple productivity dashboard for students. The idea was to make something I'd actually use: a place to keep track of study tasks, see how much progress I'm making, and stay focused while working. So it turned into a small dashboard with a task manager and a Pomodoro-style study timer built in.

## Features

- Add, complete, and delete tasks
- Filter tasks by All / Active / Completed
- Progress bar showing how much you've completed
- 25-minute Pomodoro timer with start, pause, and reset
- Tasks are saved in localStorage, so they're still there if you refresh or close the tab

## Tech Stack

- React
- Vite
- CSS
- localStorage

## What I Practiced

I built it step by step to actually understand React instead of just copying code — things like state management with useState, side effects with useEffect (for the timer and syncing with localStorage), breaking the UI into reusable components, and passing data between them with props.


## Status

Still a work in progress — planning to add more features and clean up the styling further.
